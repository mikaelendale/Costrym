# Razory - Changelog

All notable changes to Razory are documented here.

## \[v1.0.0] - 2025-08-24

**🚀 MVP Launch**

### Added

* **Tab Usage Tracking** — Monitor time spent on each active tab.
* **Focus Reports** — Daily/weekly breakdown of browsing habits.
* **Category Grouping** — Work vs. distractions (basic categories).
* **Distraction Alerts** — Simple reminders when off-task.
* **Lightweight UI** — Clean and minimal design inside Chrome.
* **Local Data Storage** — Data saved on-device for privacy.
* **Dark Mode** — Easy on the eyes during late-night focus sessions.
